Обновление системы

Установленная версия
Последняя версия GitHub

Управление обновлениями отключено в настройках helper. Проверка и установка недоступны; журнал операции остаётся доступен для чтения.

Снимок для отката не готов; доступен только повтор установки выбранной версии.

Журнал операции обновления

Состояние операции принадлежит helper и восстанавливается после перезапуска helper или панели. Потеря HTTP-ответа не запускает установку или откат повторно.

ТРЕБУЕТСЯ ПЕРЕЗАГРУЗКА СЕРВЕРА

Файлы nftables, sysctl и systemd восстановлены из одной операции, но их рабочие эффекты НЕ восстановлены. Перезагрузите сервер вручную. Автоматической перезагрузки не будет.

Перезапуск helper или панели не заменяет перезагрузку сервера.

sudo systemctl reboot
ВОССТАНОВЛЕНИЕ НЕ ЗАВЕРШЕНО

Не все файлы подтверждены как восстановленные. Повторите восстановление до перезагрузки. Изменения заблокированы. При отсутствии полной исторической копии требуется ручное восстановление оператором.

Настройки применены временно

· до отката: с

Проверьте соединение с сервером. Затем подтвердите настройки или выполните откат. При откате сетевых настроек потребуется ручная перезагрузка.

Проверка сайта выполняется с сервера. LAN forwarding требует отдельного клиента. Неуспех проверки не запрещает сохранение настроек.

Начальная настройка

Подготовка сервера

Выполните настройку в консоли сервера:

sudo xray-core-helper setup

Пошаговый диалог остановит helper и панель на время настройки. После завершения служба запустится снова; обновите эту страницу.

Предыдущая настройка требует восстановления. Откройте тот же диалог в консоли.
