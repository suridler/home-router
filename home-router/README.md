# Конфигурация шлюза

Каталог содержит примеры конфигурации Xray, nftables, sysctl и systemd для домашнего шлюза, а также вспомогательные инструменты. Это исходные примеры профиля, а не состояние конкретного сервера.

Для установки helper используйте [общую инструкцию](../docs/INSTALLATION.md). Актуальные входные шаблоны его установщика находятся в [xray-core-helper/templConf](../xray-core-helper/templConf/README.md). Не копируйте содержимое `conf/` поверх управляемых файлов установленного сервера: такие примеры могут отражать другую топологию и не содержать текущих аннотаций.

## Сетевая модель

Текущий поставляемый профиль helper перехватывает TCP/UDP выбранного LAN и исходящий IPv4-трафик самого сервера. Зарезервированные и локальные назначения, исходящие соединения Xray с bypass-маркой/группой исключаются. Корректные Xray inbound, марки, порт и policy routing должны быть согласованы до включения сети.

Имя интерфейса и подсеть выбирает оператор по реальным интерфейсам сервера. `eth2`, `lan0` и примерные адреса в исходниках не являются обнаруженными настройками хоста. Начальный `proxy` использует прямой выход, сохраняя разделение тегов `proxy` / `direct`.

Подробности: [архитектура](../docs/ARCHITECTURE.md), [эксплуатация](../docs/OPERATIONS.md), [сценарии проверки](../docs/TESTING.md).

Секреты, runtime-конфиги и базы в репозиторий не добавляются. Для исправления сетевого поведения меняйте шаблоны helper и соответствующие проверки; не создавайте второй независимый установщик.
